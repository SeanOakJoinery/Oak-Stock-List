Sync across devices

Connect this file to one shared cloud store so the same stock list shows on every phone and laptop that opens it.

  1. Create a free account at jsonbin.io.
  2. In the dashboard, copy your API key (labelled X-MASTER-KEY).
  3. Paste it below. On your very first device, leave "Bin ID" blank and click "Create shared store" — it'll fill in a Bin ID for you.
  4. Copy that Bin ID (and the same API key) into this same screen on every other phone/laptop, then click "Connect".

Link to dispatch app

Connect this stock list to your dispatch app's jsonbin store, so "Mark built" can send an item straight into the dispatch app's Unfinished column.

  1. Use the SAME jsonbin API key your dispatch app is connected with.
  2. Open the dispatch app, click "Sync across devices" there, and copy its Bin ID (not this stock list's own Bin ID — a different one).
  3. Paste both below and click Connect.
